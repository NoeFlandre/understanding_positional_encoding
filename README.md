# Understanding positional encoding

This tiny project is for educational purposes only and is kept as a standalone notebook. It aims at building understanding of positional encodings, why we need them in the 
first place and walk its way through up until RoPE. It appraoches notions of:

- Absolute positional encoding
- Sinusoidal positional encoding
- Learned positional encoding
- RoPE

The notebook might have a few typos since it is handwritten and has also been my own scratchpad while I learned these notions. I tried to frame each method using a toy example which 
hopefully might help readers.
